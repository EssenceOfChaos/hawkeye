# HawkEye: notes for Claude Code

## Spelling: American English only

Write American English everywhere: user-facing copy, emails, docs, code comments, identifiers, test names and commit messages. Do not
introduce British spellings.

| Use | Not |
|---|---|
| color, behavior, honor, favor, neighbor | colour, behaviour, honour, favour, neighbour |
| organize, organization, normalize, sanitize, summarize, authorize, serialize, customize, recognize, minimize | the -ise / -isation forms |
| analyze, analyzer | analyse, analyser |
| center, centered | centre, centred |
| canceled, canceling, labeled, labeling | cancelled, cancelling, labelled, labelling |
| defense, license (noun), catalog, gray, acknowledgment, toward | defence, licence, catalogue, grey, acknowledgement, towards |

Exceptions: `cancellation` is correct American spelling, and the HTML attribute `aria-labelledby` is spelled that way by the standard (never change it).
Third-party names and quoted external text stay as they are.
